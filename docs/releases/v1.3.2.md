# ClipShelf 1.3.2 — first downloadable preview

A small, keyboard-first macOS clipboard manager for developers. Download **ClipShelf-1.3.2-macOS-universal.zip** below; no build tools are needed.

## Install

1. Extract the ZIP and drag `ClipShelf.app` into **Applications**.
2. Open the app. A clipboard icon appears in the menu bar.
3. Copy a few items, press **⌘⌥↓ / ⌘⌥↑** to cycle, then **⌘V** to paste.

Requires **macOS 13 or later**. The same download includes **Apple Silicon and Intel** binaries.

This preview is ad-hoc signed, not Developer ID signed or notarized by Apple. macOS may block the first launch. If you trust this download, after trying to open it, use **System Settings → Privacy & Security → Open Anyway** for this app. See [Apple’s instructions](https://support.apple.com/en-us/102445).

## Included

- Text, code, image, PDF, and Finder file history.
- Keyboard cycling with a compact glass preview near a screen edge.
- Search, pins, pause, and local-only history.
- Save several text clips to one file, or mixed clips into a folder.
- A new mint-and-glass app icon.

File clips link to the original files; they must remain available. History is stored locally as unencrypted JSON. Use pause before copying secrets. To quit, right-click the menu-bar clipboard icon and choose **Quit ClipShelf**.

The `.sha256` attachment contains the checksum for the ZIP. GitHub’s automatically generated source archives are for developers; download the **macOS universal ZIP** to install the app.
